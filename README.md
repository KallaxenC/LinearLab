Simply enter a matrix and your required point, and watch the transformation video the software generates.<br/>

Supports function inputs such as `sin()`, `cos()`, `tan()`, and `sqrt()`.<br/>

All except manim calculations are manually calculated with no external modules (for example, numpy is not used). Inverse matrices are calculated using Gauss-Jordan Elimination etc.

>[!NOTE]
>The video generation relies quite heavily on the manim Python library to ensure the videos look high enough quality. Nonetheless, lower-end devices will still struggle to render 3D transformations if high-quality presets are selected in the software. If you are finding videos take a while to render, switch off unnecessary settings.
