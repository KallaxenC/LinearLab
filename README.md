Helping Visualise Linear Transformations
Simply enter a matrix and your required point and watch the transformation video the software generates.

Currently supports:
-> 2x2 matrix transformations of the unit square
-> 3x3 matrix transformations of the unit cube
-> 2D vector and point transformations
-> 3D vector and point transformations
-> Trigonometric function inputs (NEW)

All except manim calculations are manually calculated with no external modules such as numpy e.g inverse matrices are calculated using Gauss Jordan Elimination

Uses the manim python library to help generate the videos
